# 05 讓 AI 自己去裝工具

> 有些事（例如把影片裡講的話轉成文字）要額外的免費工具。你不用自己研究，AI 會去官方來源找，先交一份「安裝評估」給你，你說好它才裝。

（完整版含給人看的說明：05自己裝工具.html）

🔴 **看懂「安裝評估」才點頭**

- 要花錢、要登入、要給權限的東西，AI 一定會先講清楚。看不懂就回「用白話再說一次」。

- 電腦跳出「是否允許變更」或要你輸入電腦密碼時，確認是你剛同意的那個工具，才自己按允許。

## 你只要說

「我要用第 06 頁拆影片，幫我裝需要的工具」　或　「這個工具要不要裝：網址」

## 這包會用到的工具（都免費，用到哪一頁再裝哪一個）

工具｜做什麼用｜官方來源｜

Python｜讓轉文字的工具跑起來｜python.org｜

yt-dlp｜下載公開影片的聲音，拿來轉文字（只用來學習）｜GitHub：yt-dlp/yt-dlp｜

ffmpeg｜幫 yt-dlp 把影片轉成聲音檔｜ffmpeg.org（Windows 用 gyan.dev 版）｜

faster-whisper｜把聲音轉成文字｜GitHub：SYSTRAN/faster-whisper｜

只拆文章、只看說明文字的話，一個都不用裝。真的要拆影片再裝。

## 安裝評估長這樣

**yt-dlp**

是什麼：開源的影片下載工具，很多人用它把公開影片存下來。

幫你做什麼：拆影片時，先把影片的聲音抓下來，再交給轉文字工具。

要花錢嗎：免費，不用登入。

會裝在哪：你的電腦裡，不到 20MB。

風險：從官方來源裝，沒有已知風險；只拿來學習，不拿別人的影片重新發布。

怎麼移除：說「幫我移除 yt-dlp」。

**建議：要拆影片就裝，只看文章就先不用。**

## 網路上看到別的工具，裝之前它會先查三件事

- **誰做的**：作者經營多久、有沒有很多人一起維護、有沒有人回報怪事。星星數只當參考，不能證明安全。

- **是不是正版**：從官網的連結進 GitHub，不從來路不明的轉貼連結。

- **安裝時會跑什麼**：要你直接執行一段下載來的指令時，它會先把內容印出來給你看。

## 給 AI 員工的工作單：使用者要裝工具時

同一頁的純文字版在 `懶人包/給Claude讀/`（網址：`https://bryanlin1531.github.io/ai-assistant/給Claude讀/05自己裝工具.md`），內容相同，AI 可以直接讀那份。使用者是貼網址給你、工作資料夾裡沒有「懶人包」資料夾時，這頁提到的 `懶人包/○○` 檔，到 `https://bryanlin1531.github.io/ai-assistant/` 後面接同樣的路徑讀（不用先下載整包）。
這頁做完，告訴使用者下一頁是「06 打造你的 AI 學習助手（輕量版）」；他說「下一頁」，就讀 `https://bryanlin1531.github.io/ai-assistant/給Claude讀/06學習助手.md` 照著做。

【先確認】先看使用者是 Windows 還是 Mac，再查工具是不是已經裝了（例如 `yt-dlp --version`、`ffmpeg -version`）。裝過的不重裝。

【這樣做】

- 只從上表的官方來源裝。

- Windows 用內建的 winget：Python＝`winget install Python.Python.3.12`、yt-dlp＝`winget install yt-dlp.yt-dlp`、ffmpeg＝`winget install Gyan.FFmpeg`；faster-whisper 用 `pip install faster-whisper`。

- Mac 用 Homebrew：`brew install python yt-dlp ffmpeg`；faster-whisper 裝進獨立環境：`python3 -m venv ~/ai-tools` 再 `~/ai-tools/bin/pip install faster-whisper`。電腦還沒有 Homebrew 時，先給安裝評估，並說明它的官方安裝指令來自 brew.sh。

- 裝之前先交「安裝評估」（照上面的格式：是什麼、幫你做什麼、要不要花錢、裝在哪多大、風險、怎麼移除、建議＋一句理由），等使用者同意。

- 使用者給的工具不在表上：照上面「裝之前先查三件事」查過，再交安裝評估。來源不明的建議不裝。

- 提醒使用者電腦會跳出允許視窗或要求電腦密碼，請他確認後自己按、自己輸入。

- 裝好實際跑一次（例如 `yt-dlp --version`），把結果給使用者看；在 `進度與下一步.md` 的「地圖」記下裝了什麼。

【交件標準】工具裝好、實測可以跑；使用者知道裝了什麼、怎麼移除。

【紅線】沒交安裝評估就裝；要花錢、要登入或要帳號權限的東西沒先問；從不明網站下載；改電腦的安全設定；替使用者輸入電腦密碼。
