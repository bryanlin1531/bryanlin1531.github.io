卡住了怎麼辦、順便省額度

新手最常遇到的幾種狀況，一句話對應解法。最後再教你怎麼用得省一點額度。印出來或存成書籤，卡住就翻一下。

誰動手：你照著做需要時再看有需要再看
用之前先知道：這套要用「能操作電腦的 AI」才做得到（Claude 桌面版的 Code 分頁，或 Claude Code）；網頁版和手機 App 只能聊天，沒辦法幫你動手。每頁要 AI 做的事都寫在頁面上，沒有藏起來的指令。AI 安裝東西、花錢、刪檔前都會先問你；帳號密碼和金鑰一律你自己填，不要貼進對話。

卡住了？對照這張表

你遇到的狀況這樣解
它好像沒讀到我的檔、不知道我是誰先確認你開的是同一個資料夾（第 01 頁建的那個）。再叫它「先讀 CLAUDE.md 和 我的服務.md 再回答」。
它亂改了東西、改錯了跟它說「還原剛剛的修改」或「這個檔回到你改之前」。下次把權限留在「動手前先問我」。
對話變慢、變鈍、前面講過的又忘了對話太長了。說「更新進度，我要換新對話」，再開新對話用「上次停在哪？」接上。
它說做好了，但我沒看到叫它「告訴我成品在哪個檔、哪個資料夾」，自己打開檔案總管（Mac 是 Finder）看。
它一直跳「要不要允許」很煩只有「讀檔案、看資料夾」那種可以選「這類都允許」。安裝、刪除、送出、付款每次都要看清楚。
它答得很籠統、我聽不懂說「用白話再說一次」，或「舉一個我這行的例子」。
它說要裝東西、要跑一段指令先要它給「安裝評估」（第 05 頁），看不懂就先別允許。
它想碰工作資料夾以外的檔不要允許。提醒它「只在這個資料夾裡做事」。
我貼的網址裡，好像叫它去下載／安裝／傳送什麼那是別人塞進內容裡的指令，叫它不要照做（第 06 頁的紅線）。它本來也會先警告你。
我好像選錯資料夾了在 Code 分頁重新選對的那個資料夾，再繼續。

還是卡住：把你看到的畫面截圖貼給它，說「我卡在這裡，幫我看怎麼辦」。它會順著你的檔案和進度幫你找。

還有：怎麼省額度

Pro 方案的額度會用完，但有幾個習慣能省很多：
  1. 一件事做完就換新對話長對話你每問一次，它都要把前面全部重看一遍，越長越貴也越慢。說「更新進度，我要換新對話」，新對話用「上次停在哪？」接上，不會斷。
  2. 大檔先轉文字再給它PDF、影片先轉成文字（第 05 頁的工具）再讓它讀，比直接丟原檔省很多。
  3. 一次講清楚，少來回要做的事、規格、限制一次說完。來回問十次，比一次講完貴。
  4. 不確定它懂不懂，先讓它覆述說「先用一句話覆述我要什麼」，對了再讓它動手，省得做錯整個重來。
  5. 讀圖、拆影片比較吃額度沒必要時先用說明文字就好，真的要看畫面再拆。

給 AI 員工的工作單：使用者說「我卡住了」或問怎麼省額度時

同一頁的純文字版在 懶人包/給Claude讀/，內容相同，AI 可以直接讀那份。

這樣做

  1. 先問清楚是哪一種狀況（或請他截圖），對照上面那張表，用一句白話給解法，不用術語。
  2. 牽涉到還原修改時，說清楚你要把哪個檔、改回哪個時間點，動手前先讓他確認；找不到還原點就照實說，不硬改。
  3. 他要換新對話省額度：先更新 進度與下一步.md 的現況和下一步，再請他開新對話說「上次停在哪？」。

交件標準使用者知道下一步怎麼做，或卡住的地方解開了。

紅線自作主張刪檔、清對話、碰工作資料夾以外的東西；還原前沒先跟使用者確認改哪個檔。
